# DS & AI Cookbook

End-to-end recipes for data science, machine learning, deep learning, data engineering, AI engineering, LLMOps, DataOps, generative sciences and technical auditing. Each recipe solves **one problem**, compares **every viable stack** and measures the effect of the **decision variables**, from introductory to SOTA. Integrating projects focus on **finance, economics and socioeconomics**.

## How to use it

- **Have a problem?** Search or browse the [Recipes](recipes/A-foundations/index.md). Start with each recipe's **decision map**.
- **Want to build a full system?** See the [Projects](projects/index.md), each in three tiers: minimal (L1), production (L3) and SOTA (L4).
- **Want to run it?** Every notebook opens in Google Colab from the button at the top.

| Level | Meaning |
|---|---|
| 🟢 L1 · Introductory | first time; small dataset, one machine |
| 🟡 L2 · Intermediate | real project; medium scale, good practices |
| 🟠 L3 · Advanced | production, scale, fine trade-offs |
| 🔴 L4 · SOTA | research and engineering frontier |
