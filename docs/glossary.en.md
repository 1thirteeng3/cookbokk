# Glossary

Terminology reference (SPEC.md §5). The table shows how each term is written in the Portuguese text, so both versions stay consistent. Add a term here before using it.

| Term | Use in PT text | Short definition |
|---|---|---|
| baseline | *baseline* | Trivial model or rule used as the minimum performance reference. |
| benchmark | *benchmark* | Controlled comparison of stacks: same data, splits, seeds and metrics. |
| data leakage | vazamento de dados (*data leakage*) | Information unavailable at prediction time that enters training. |
| drift | *drift* | Change in the data distribution or in the input–target relationship over time. |
| embedding | *embedding* | Learned dense vector representation of an object (text, image, entity). |
| feature | *feature* | Input variable of a model. |
| fine-tuning | *fine-tuning* | Adapting a pretrained model on specific data. |
| pipeline | *pipeline* | Chained, reproducible sequence of processing steps. |
| parent recipe | receita | Cookbook unit: one problem with every viable stack. |
| stack | *stack* | Concrete set of tools used to solve a problem. |
| threshold | ponto de corte (*threshold*) | Value that turns a score into a decision. |
| WoE / IV | *Weight of Evidence* / *Information Value* | Transformation and predictive-power measure used in credit scorecards. |
