# DS & AI Cookbook

Receitas end-to-end de ciência de dados, machine learning, deep learning, engenharia de dados, AI engineering, LLMOps, DataOps, ciências generativas e auditoria técnica. Cada receita resolve **um problema**, compara **todas as stacks viáveis** e mede o efeito das **variáveis de decisão**, do nível introdutório ao SOTA. Os projetos integradores têm foco em **finanças, economia e socioeconomia**.

## Como usar

- **Tem um problema?** Procure na busca ou navegue pelas [Receitas](recipes/A-foundations/index.md). Comece pelo **mapa de decisão** de cada receita.
- **Quer construir um sistema completo?** Veja os [Projetos](projects/index.md), cada um em três camadas: mínima (L1), produção (L3) e SOTA (L4).
- **Quer rodar?** Todo notebook abre no Google Colab pelo botão no topo.

| Nível | Significado |
|---|---|
| 🟢 L1 · Introdutório | primeira vez; dataset pequeno, uma máquina |
| 🟡 L2 · Intermediário | projeto real; escala média, boas práticas |
| 🟠 L3 · Avançado | produção, escala, trade-offs finos |
| 🔴 L4 · SOTA | fronteira de pesquisa e engenharia |
