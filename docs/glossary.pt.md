# Glossário

Referência de terminologia (SPEC.md §5). Termos consagrados ficam em inglês no texto em português, em *itálico* na primeira ocorrência da página. Adicione o termo aqui antes de usá-lo.

| Termo | Uso no texto PT | Definição curta |
|---|---|---|
| baseline | *baseline* | Modelo ou regra trivial usado como referência mínima de desempenho. |
| benchmark | *benchmark* | Comparação controlada entre stacks: mesmos dados, splits, seeds e métricas. |
| data leakage | vazamento de dados (*data leakage*) | Informação indisponível no momento da previsão que entra no treino. |
| drift | *drift* | Mudança na distribuição dos dados ou na relação entre entradas e alvo ao longo do tempo. |
| embedding | *embedding* | Representação vetorial densa aprendida de um objeto (texto, imagem, entidade). |
| feature | *feature* | Variável de entrada de um modelo. |
| fine-tuning | *fine-tuning* | Ajuste de um modelo pré-treinado em dados específicos. |
| pipeline | *pipeline* | Sequência encadeada e reprodutível de etapas de processamento. |
| receita-mãe | receita | Unidade do cookbook: um problema com todas as stacks viáveis. |
| stack | *stack* | Conjunto concreto de ferramentas usado para resolver um problema. |
| threshold | ponto de corte (*threshold*) | Valor que converte um score em decisão. |
| WoE / IV | *Weight of Evidence* / *Information Value* | Transformação e medida de poder preditivo usadas em scorecards de crédito. |
